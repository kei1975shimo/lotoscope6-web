# ロト・スコープ v1.16.0 Mystic Oracle

誕生日 × 日本時間の日付 × 占術 × 券種から、その日の数字候補を導くFlaskアプリです。
西洋占星術・カバラ数秘術・タロット、およびミニロト・ロト6・ロト7・ナンバーズ3/4に対応します。

## この版の変更

- 毎日共通の最大10口を先に生成してスコア順に固定。口数を変えても先頭と順番が一致します。同点は生成順です。
- 43個の重みを各券種の範囲へ等幅の区間平均で変換。剰余の折り返しによる二重加算を除きました。ナンバーズの0〜9も同じ方式です。
- 偽装した転送ヘッダーの先頭をIPとして信用する処理を削除。信頼するプロキシ数を設定する方式に変更しました。
- 画像3点を新規作成し、占術選択・結果・演出に組み込みました。星読み盤の回転、生命の樹の点灯、タロットの展開・反転を使い分けます。
- 初回・再確認とも、送信と演出を同時に開始。通信失敗、時間切れ、キャンセル時も入力を保って再操作できます。
- 誕生日プレビューはCSRF付きPOSTへ変更。通常操作で誕生日をURLに載せません。
- HTML/CSS/JSを整理。旧CSV用ユーティリティ、旧API、互換エイリアス、古い画像、重複していた説明書を削除しました。
- JavaScriptを使えない場合も、年月日の選択と通常のフォーム送信で生成できます。

**生成式を修正したため、v1.15.0と数字は変わります。v1.16.0の同じ設定同士では、その日の数字が固定されます。**
設定の最大口数を変更した場合も候補集合が変わるため、公開後は `max_ticket_count=10` を維持してください。
「一日一回」は日ごとの固定結果という意味です。何度確認しても利用できます。翌日も偶然同じ組み合わせになる可能性はあります。

## 起動と更新

- Windowsで起動：`LOCAL_RUN_JA.md`
- 既存のRenderサイトへ反映：`UPDATE_EXISTING_SITE_JA.md`
- 修正内容と検証結果：`docs/verification_ja.md`
- セキュリティの設定・限界：`docs/security_notes.md`
- 画像の説明と生成プロンプト：`docs/artwork.md`

実行時に外部の占いAPI・フォント・画像サービスへ接続しません。
生年月日や生成結果は、サーバーのDB、CSV、ログ本文、Cookie、ブラウザー保存領域へ書き込みません。
結果画面の再確認用フォームには生年月日が含まれますが、表示項目には出しません。画面更新で入力に戻ります。

## 検証コマンド

Python 3.10以降で依存関係をインストールして実行します。

```powershell
python -m unittest tests.smoke_test tests.regression_test -v
python tests/generation_matrix.py
```

オフラインDOMテストはNode.js 24.15以降の24系など、package.jsonの対応バージョンが必要です。公開時には不要です。

```powershell
npm ci
npm test
```

Pythonの場所を指定する場合は、先に `$env:PYTHON='.\.venv\Scripts\python.exe'` を設定します。
DOMテストは、実際のFlaskテンプレートを読み込み、通信応答と時間を模擬して操作を確認します。描画エンジン・Safari/iPad実機での見た目を検証するものではありません。

## 数字と占い

出生時刻・出生地を使わない簡易星読み、および数秘術・タロットを参考にした独自方式です。
占術ごとの重み付けと極端な数字構成を避ける判定は残しています。出現頻度を全数字で均一にする設計ではありません。
点数は占いとの結びつきの目安であり、当せん確率ではありません。当せんを保証しません。
