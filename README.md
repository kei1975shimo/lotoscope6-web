# ロトナンバーズ・スコープ 公開用Flask版 v1.7.9

生年月日と生成日の七天体から、数字選択式宝くじの候補を導くスマートフォン向けWebアプリです。

画面上の名称は **ロトナンバーズ・スコープ**、英字表記は **LOTO NUMBERS SCOPE** です。

## 対応している宝くじ

- ミニロト：1〜31から異なる5個
- ロト6：1〜43から異なる6個
- ロト7：1〜37から異なる7個
- ナンバーズ3：0〜9の3桁。重複と並び順を保持
- ナンバーズ4：0〜9の4桁。重複と並び順を保持

ナンバーズは文字列として扱うため、`007`や`0038`の先頭の0も消えません。

## ローカル起動

Python 3.10以降を推奨します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:SECRET_KEY='任意の長い文字列'
python app.py
```

すでに仮想環境と依存関係を作成済みの場合は、次だけで起動できます。

```powershell
.\.venv\Scripts\Activate.ps1
python app.py
```

ブラウザで `http://127.0.0.1:8786` を開きます。

## Renderへの公開

このフォルダには次の公開用ファイルが含まれています。

- `render.yaml`
- `Procfile`
- `requirements.txt`
- `app.py`

Renderでは必ず環境変数 `SECRET_KEY` を設定してください。既存サイトを更新する場合は、フォルダ全体を置き換えて再デプロイします。

## 星読みについて

出生時刻と出生地を使わない簡易星読みです。生年月日と生成日の正午（日本時間）における太陽、月、水星、金星、火星、木星、土星の位置と主要アスペクトを、選んだ券種の数字範囲または各桁へ変換します。

生成結果や点数は、数字選びを楽しむための独自の目安です。当せん確率や当せんを保証するものではありません。
