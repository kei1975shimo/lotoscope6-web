# v1.7.0 五つの星の儀式

## 名称変更

画面上の名称を「ロトナンバーズ・スコープ」に変更しました。
英字表記は `LOTO NUMBERS SCOPE` です。

## 券種別の生成演出

- ミニロト：月輪の五光
  - 月の円環、五つの星、月光をイメージした演出
- ロト6：六星印の儀
  - 六芒星、六つの天体印、封印が解ける演出
- ロト7：七惑星の大軌道
  - 七天体が異なる軌道を巡り、中央へ収束する演出
- ナンバーズ3：三連星盤
  - 三つの数字盤が回り、左から順に桁を定める演出
- ナンバーズ4：四星門の啓示
  - 四つの星門が一枚ずつ開き、四桁を結ぶ演出

各券種で、色、紋章、説明文、進行時間、数字の出現方法を変えています。

## 結果画面

生成結果にも券種ごとの色と紋章を引き継ぎました。
数字の出現方法は次のように変わります。

- ミニロト：月光から数字が降りる
- ロト6：六星印から中央へ集まる
- ロト7：惑星軌道から収束する
- ナンバーズ3：星盤が回転して停止する
- ナンバーズ4：星門が開いて数字が現れる

端末で「視差効果を減らす」「アニメーションを減らす」が設定されている場合は、短い静的表示へ自動的に切り替わります。
