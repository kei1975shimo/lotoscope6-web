# v1.9.1 ロト専用・モバイルコンパクト版

## 変更内容

- 対応券種をミニロト・ロト6・ロト7の3種類に限定。
- ナンバーズ3 / ナンバーズ4の製品定義、生成処理、画面、演出を削除。
- ブランド表記を「ロト・スコープ / LOTO SCOPE」へ統一。
- トップの説明セクション、最終確認ブロック、重複する説明文を削除。
- スマートフォンではヒーローの大型天球グラフィックを非表示にし、タイトル部分を圧縮。
- ロト3種類の選択カードをスマートフォンでも横3列にして、縦スクロールを短縮。
- 誕生日入力、口数、実行ボタン周辺の余白と高さを縮小。

## 目的

スマートフォンで開いた直後から主要操作へ早く到達できるようにし、
「ロトを選ぶ → 誕生日 → 口数 → 数字を受け取る」という流れへ集中させる。
