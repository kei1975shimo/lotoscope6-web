# v1.2.0 スマートフォン優先UI全面改修

## 改修理由

旧画面は「スマホ向け」を掲げながら、説明文・補足・カード内の文字に10〜13px台が多く、実際のスマートフォンでは読みづらい状態でした。また、3列表示や横並びの結果カードなど、画面幅より装飾を優先した箇所がありました。

## 文字設計

- 本文: 17px
- 補足・説明: 14px以上
- 入力ラベル: 16px
- 入力欄: 17px
- 数字入力: 22px
- ボタン: 17px
- セクション見出し: 25px前後

装飾目的の極小文字を除き、利用者が読む文章は原則12px未満にしない設計です。

## 操作設計

- 主ボタンの高さを60pxへ拡大
- 補助ボタンの高さを52pxへ拡大
- 数字入力欄を58px以上へ拡大
- ページ内ナビを44px以上のタップ領域に変更
- 生成方法カードを最低124pxの高さに変更
- 結果・照合画面の操作バーをスマホで下部追従に変更

## レイアウト

- 390px未満では概要カードを2列＋全幅に変更
- 買い目とスコアを狭い画面では縦配置
- 360px、390px、600pxで横スクロールなしを確認
- 430px以上、560px以上で段階的に2列表示へ移行

## デザイン

- 夜空、艶、浮遊感、ゴールド、ネオンを基本方向として維持
- 旧トップ画面の大きな天体リングを、6個の数字が見える買い目プレビューへ変更
- 文字のコントラストを上げ、暗い背景でも読みやすく調整
- 選択状態を枠色だけでなくラジオ表示でも示すよう変更

## 確認

- 自動テスト8件成功
- Flaskテストクライアントによるトップ・生成結果・照合画面の描画確認
- 360px、390px、600px幅で `scrollWidth` が画面幅を超えないことを確認
- 390px幅のトップ、生成結果、照合画面を画像確認
