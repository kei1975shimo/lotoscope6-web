# v1.0.16 lotus rebuild(占星術ロータスUI 再構築)

v1.0.9〜v1.0.15にかけて`!important`の重ね上書きで進化してきたCSSを、
「占星術ロータス」を唯一の正式デザインとして一から再構築しました。

## 直した不具合

- `.small-button` / `.ghost-button` などが複数箇所で別々に定義されており、
  `<a>`タグのボタンと`<form><button>`のボタンで高さ・パディングが食い違って
  隣り合う場面(結果画面の「戻る / 照合する」など)でずれて見える問題を解消。
  ボタン系セレクタを1か所に統合し、高さ・角丸・余白の基準を共通化。
- `.sticky-mobile-nav`と`.action-row.compact-actions`が同じ`top`位置で
  二重にstickyになり、スクロール時に重なっていた問題を解消
  (結果画面のアクション行は通常フローに戻し、下部固定バーに操作を集約)。

## 見た目の変更

- ネイビー×ゴールドの占星術ロータストーンに統一(iPhoneライクな明るいUIから変更)
- 見出しに明朝体(Shippori Mincho)を採用し、占星術らしい世界観を強化
- ヒーローの天球儀(orbital)モチーフをゆっくり回転させ、アプリらしい生きた質感を追加
- 数字ボール・カード・ローダーは占星術トーンで再配色(低=蒼、中=翠、高=金、32以上=菫)

## 追加したモーション

- ボタン・モードカードのタップ時の縮小フィードバック
- アプリバー・ヒーロー・パネルのフェードイン表示
- 下部固定バーのせり上がり表示、結果の数字ボールの順送りポップイン
- iOS Safari向けにタップフィードバックが確実に効くよう`touchstart`リスナーを追加
- `prefers-reduced-motion`環境ではアニメーションを無効化

## ロジックへの影響

買い目生成ロジック、数字スコア計算、照合判定ロジックは変更していません。
`base.html`のbodyクラスと`<head>`(Google Fonts読み込み)のみ変更し、
他のテンプレートのクラス構造は変更していないため、既存の`app.py`との互換性は保たれています。
