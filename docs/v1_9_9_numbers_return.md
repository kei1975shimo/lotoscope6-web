# v1.9.9 ナンバーズ3・ナンバーズ4 復活版

## 変更内容

v1.9.1で「ロト専用」へ整理された際に削除したナンバーズ3・ナンバーズ4を、星読み対応の新規実装として復活させました。
過去の実装の復元ではなく、Celestial Patterns（v1.9.8）のデザイン言語に合わせた新しいコードです。

- `src/product_numbers.py` にナンバーズ3（3桁）・ナンバーズ4（4桁）の商品定義を追加
- 生年月日と生成日の七天体の重み（1〜43）を0〜9の桁へ畳み込む `build_digit_weights` を新設
- 桁ごとに独立して重み付き抽選する生成ロジック（`_generate_numbers_rows`）を追加。ロトと異なり、同一桁内での重複（例: 1-1-2）を許容
- 表示は「ストレート」（生成順そのまま）を主表示、「ボックス」（並べ替え）を参考情報として併記
- トップ画面の券種スイッチにナンバーズ3・ナンバーズ4を追加（天体シンボル・星図装飾は既存の意匠を流用）
- 結果画面はロトの円形ボール（`.num`）ではなく、既存CSSに残っていた `.digit-tile` 意匠（角丸タイル・星読み中心桁のハイライト）で表示
- 読み込み中の「儀式」演出にナンバーズ3（三つの星読盤 `.celestial-dial`）・ナンバーズ4（四つの星の門 `.star-gate`）を追加。CSS側には元々このアニメーションが残っていたため、それを活用
- `tests/smoke_test.py` を更新し、「ナンバーズが混入していないこと」を検証していたテストを、「ナンバーズ3・4が正しく生成・表示されること」を検証するテストへ置き換え

## 設計メモ

- ナンバーズは本来「ストレート」（順序あり）の宝くじのため、`numbers` の各行は生成順のまま保持し、並べ替えはしない
- 桁の重複を許容するため、ロトの「一意な組み合わせ抽選」ロジックとは別関数で実装
- 星読みの「参考にした中心桁」は、既存の `core_numbers` / `pool_numbers`（1〜43ベース）を10で畳み込んで導出（`% 10`）
- 過去の抽せんデータ・当せん確認機能は引き続き使用しない方針を維持

## 復元にあたっての注意

このプロジェクトはv1.9.1で「ロト専用・モバイルコンパクト版」として意図的にナンバーズを削除し、混入防止のテストまで用意していました。
v1.9.9はその方針を利用者の希望により転換し、ナンバーズを再度対応商品として組み込んでいます。
