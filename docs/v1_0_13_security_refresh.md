# v1.0.13 security refresh

公開テスト向けに、安全性と運用しやすさを補強しました。

## 変更内容

- 本番環境で `SECRET_KEY` が未設定の場合は起動停止
- 生成結果トークンを期限付き署名へ変更
- POSTフォームにCSRFトークンを追加
- IP単位の簡易レート制限を追加
- セキュリティヘッダーを追加
- 過去データが14日以上古い場合の注意表示を追加
- データ更新手順ドキュメントを追加
- 配布ZIPから `__pycache__` / `*.pyc` を削除

## ロジックへの影響

買い目生成ロジック、数字スコア計算、照合判定ロジックは変更していません。
