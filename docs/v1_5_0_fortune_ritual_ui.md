# v1.5.0 Fortune Ritual UI

## 変更内容

- 標準的な占いサイトを意識し、生年月日を「西暦・月・日」の3セレクターへ変更。
- 日付選択後に「星図への刻印」として入力内容を確認できる表示を追加。
- 生成前に約4.4秒の占断演出を行う。
- 占断は「誕生星図」「現在天体」「数字の記憶」「六つの数字」の4段階。
- 六つの光が順番に点灯してからサーバーへ生成リクエストを送る。
- 結果画面の星読み数字と総合スコア1位の数字を順番に表示。
- `prefers-reduced-motion` 利用者には演出を短縮し、過度な動きを止める。

## 注意

演出時間は占い体験を高めるための表示であり、計算精度や当せん確率を示すものではない。
