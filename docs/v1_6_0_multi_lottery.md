# v1.6.0 複数券種対応

## 主な変更

- 「バランス」「過去データ」「眠っている数字」「高い数字を含める」「五つの導きをすべて試す」を画面から削除
- 生成方式を星読みに統一
- 次の5券種に対応
  - ミニロト：1〜31から異なる5個
  - ロト6：1〜43から異なる6個
  - ロト7：1〜37から異なる7個
  - ナンバーズ3：0〜9の3桁（重複可・並び順を保持）
  - ナンバーズ4：0〜9の4桁（重複可・並び順を保持）
- ナンバーズは文字列として扱い、`007`や`0038`の先頭の0を保持
- 券種ごとに結果表示・中心数字・生成演出の文言を切り替え
- 全券種で手入力による答え合わせに対応
- ロト6のみ、従来の同梱データによる抽せん回照合を継続
- ブランド表記を `LOTOSCOPE 6` から `LOTOSCOPE` へ変更

## 画面の流れ

1. 生年月日を入力
2. 宝くじを選択
3. 口数を指定
4. 星読みを開始
5. 最も強く響いた数字を先に表示
6. 星読みの理由と他候補を確認
7. 抽せん後に答え合わせ

## 注意

星読みは数字選びを楽しむための機能です。当せんを保証するものではありません。
