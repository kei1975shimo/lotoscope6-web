# v1.5.6 生年月日セレクト表示修正

## 症状

iPhone系ブラウザで、10月・11月・12月や10日以降を選択すると、選択欄では左側の1桁だけが見え、右側の数字が「月」「日」の重ね表示に隠れることがありました。

## 原因

ネイティブの `select` 上に単位を絶対配置していたため、iPhoneブラウザ独自の選択値描画位置と重なっていました。

## 修正

- 各選択肢の表示文字を `2000年`、`10月`、`11日` の形式に変更
- 重ねていた単位要素を削除
- 値そのものは従来どおり数値なので、生成ロジックには影響なし
- `box-sizing`、中央揃え、右側余白を調整
- 古いHTMLがキャッシュされた場合に備えて、旧単位要素もCSSで非表示
- キャッシュ識別子を `v1.5.6-public` に更新

## 確認項目

- 2000年10月11日が3つの欄で完全に表示される
- 12月31日が欠けずに表示される
- 隠し入力値は `YYYY-MM-DD` のまま維持される
- 星座プレビューと生成処理が従来どおり動作する
