# v1.10.0 オーロラ・ヴェール（配色一新）

## 変更内容

ボタンの構造・機能・レイアウトは変更せず、視覚的な配色のみを一新しました。
星座・惑星などのシンボルはすべて維持し、光・線・グラデーションで神秘性を高める方向で調整しています。

- 全体の配色を「ダーク×ゴールド」から「深い青紫・オーロラ調（インディゴ／バイオレット×ティール×ローズ）」へ変更
- CSS内に残っていた複数世代の `:root` 定義（v1.2.0 / v1.4.0 / v1.7.0）のうち、実際にブラウザで有効になっていた層を特定し、そこを含めて色を統一
- 金色系のRGB値・HEX値をプログラム的に彩度・明度を保ったまま紫系へ変換（約220箇所）し、手作業では起きやすい調整漏れを防止
- 5券種（ミニロト・ロト6・ロト7・ナンバーズ3・ナンバーズ4）のテーマカラーを、識別しやすいオーロラ系スペクトラムへ再構成
  - ミニロト：氷青
  - ロト6：紫〜マゼンタ
  - ロト7：ティーングリーン
  - ナンバーズ3：深い藍紫
  - ナンバーズ4：ローズピンク
- トップ画面・結果画面のヒーローに、紫→ティール→ローズのグラデーションで光る「オーロラ・リボン」SVGを新規追加（signature要素）
- ページ背景に、ゆっくり揺らめくオーロラ状の光のアニメーションを追加（`prefers-reduced-motion` に対応し、設定時は静止）
- スキップリンク・ボタンなど、明るい配色に切り替わった要素のテキストコントラストを個別に調整

## 変更していないもの

- ボタンの配置・サイズ・タップ領域・インタラクション（押下時の縮小など）
- フォーム構成、生成ロジック、券種の並び順
- 星座記号・惑星記号・儀式演出（ローディング画面のアニメーション種別）そのもの
