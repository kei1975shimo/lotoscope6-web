# v1.1.0 公開画面・入力検証の全面改修

## 目的

公開利用者が、表示されている言葉と実際の処理を同じ意味で理解できるようにし、入力ミスや照合ミスを防ぐための改修です。数字生成の基本的な評価式とRender公開構成は維持しています。

## 主な変更

### 生成口数

「全モード比較」は、指定した口数を5種類それぞれに生成します。画面上に合計予定口数を即時表示します。初期値は各2口、合計10口です。

### 生成方法の名称

- バランス型 → 総合バランス型
- データ重視型 → 過去データ重視型
- 未出現数字重視型 → 出現間隔重視型
- 高配当意識型 → 32〜43重視型

配当を直接予測しているように見える表現や、「一度も出ていない」と誤解される表現を削除しました。

### 総合スコア

総合スコアは次の4項目を重み付けした、候補比較用の独自評価です。

- 過去データ評価: 40%
- 数字構成評価: 30%
- 入力数字との適合: 15%
- 32〜43の配分: 15%

当せん確率ではないことを生成画面と結果画面に明記しています。

### 照合

照合方法をラジオボタンによる明確な二択に変更しました。

- 同梱データ内の抽せん回を指定
- 本数字6個とボーナス数字を直接入力

本数字の重複、範囲外、ボーナス数字と本数字の重複はエラーになります。

### 操作導線

- 生成結果から、入力済み条件を保ったまま再編集可能
- 照合結果から、照合条件を保ったまま再照合可能
- 照合結果では、実際に存在する最高一致グループを最初から開く
- 「開く／閉じる」の表示を状態に合わせて更新
- 入力中の固定ボタンによる画面の覆い隠しを廃止

### 処理と安全性

- 再現用キーワードによる乱数をリクエスト単位に分離
- 全モード比較時の買い目重複をモード横断で防止
- 不正なモード、口数、重複入力をサーバー側でも検証
- 公開画面に内部例外をそのまま表示しない
- CSP、Permissions-Policy、no-storeを追加
- レート制限用の古いIPバケットを定期整理
