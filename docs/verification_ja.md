# 修正・検証記録 v1.16.0

## ご指摘への対応

| 項目 | 対応 |
|---|---|
| 口数で最上部が変わる | 共通の10口を生成・安定ソートし、必要口数だけ返す。結果の見出しは必ずrows[0]。追加候補は2口目から表示し、重複表示を除去。 |
| 転送ヘッダー偽装 | ヘッダー先頭の直接参照を削除。直接接続は無視、設定済みプロキシ経由はProxyFix後のIPで制限。ロック付きでスレッド間の競合も防止。 |
| 低い数字への折り返し偏り | 共通範囲を等幅区間へ写し、重なり長に応じて平均。元の重みが一様なら移した先も完全に一様。ナンバーズも対応。中心数字も同じ座標系へ変換。 |
| 再確認に演出がない | 初回と再確認を共通の送信処理へ接続。占術名・ボタン表示も実際の選択に連動。不要属性を削除。 |
| 演出後に通信を開始 | 送信を即時開始し、応答と演出完了の両方を待つ方式へ。異常時は演出を閉じて入力を維持。勝手な再送は行わない。 |
| 未使用コード・日時 | CSV用utils.py、旧/zodiac-preview、未使用importと互換フィールドを削除。未表示のgenerated_atも削除。日付はリクエストごとにJSTで一度確定。 |
| CSS・画像 | 現行UIだけでCSSを再構成。画像3点を新規作成し512pxのWebPに最適化。全imgに寸法とaltを指定。旧画像を削除。 |

さらに、プレビューの生年月日をGETのURLからCSRF付きPOSTへ移しました。
JavaScriptなしの年月日選択、通信失敗・タイムアウト・キャンセル・二重送信防止、キーボード操作、動きを減らす設定にも対応しました。

生成式の変更により、旧版の数字との互換性はありません。同じv1.16.0・同じ設定の中で日ごとの一貫性を保ちます。
スコア順は当せんしやすさの順位ではなく、本アプリの占いの重みとの結びつきです。

## 未確認の範囲

そのため、実ブラウザーの描画・アニメーションの見え方・スマホやiPadでのタップ操作は未確認です。
DOMテストはレイアウトの描画検証ではありません。画面幅に応じたCSSは実装しています。

Render本番への反映と実際のプロキシ経路も未確認です。更新方法はUPDATE_EXISTING_SITE_JA.mdにまとめています。
